Assistant

The keyword planner is a simple rule-based baseline without an LLM. It only understands questions phrased like the benchmark templates; use it to test the app when the LLM server is not running.

Your feedback

Use 👍 / 👎 under answers and Correct the cell state on a cell card. Answers marked good are shown to the assistant as worked examples for similar questions; corrected states become labels for the next cell-state model, which only replaces the current one if it does at least as well on the locked test. Feedback stays on this server.
